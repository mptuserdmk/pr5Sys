# Практическая работа №5: Аналоговые датчики, analogRead(), map()

Аппаратно-программный комплекс моделирования автомобильного парктроника («датчик парковки») на базе микроконтроллера Arduino Uno с использованием аналогового фоторезистора, светозвуковой индикации (зуммер + светодиод), неблокирующих таймеров `millis()`, автокалибровки освещения и внешнего аппаратного прерывания `INT0`.

## Стек технологий
- C / C++ (Arduino Wiring)
- Arduino Uno (ATmega328P)
- 10-разрядный АЦП (ADC), аппаратные таймеры, внешние прерывания (INT0)
- Cirkit Designer / Autodesk Tinkercad / Wokwi

## Состав репозитория
- `sketch.ino` — исходный код микроконтроллера
- `circuit_image.png` — принципиальная схема подключения в эмуляторе
- `Отчет.md` — отчет по практической работе №5
- `Девлет М.К. Отчет .docx` / `.pdf` — индивидуальный отчет
- `Девлет М.К. Отчет (Практические №1-№5).docx` / `.pdf` — сквозной отчет по практическим работам №1–№5
- Интерактивная схема: [Cirkit Designer](https://app.cirkitdesigner.com/project/41090fec-b92a-40f8-b21c-a15b956f2572)

## Запуск
1. Откройте `sketch.ino` в Arduino IDE или симуляторе (Cirkit Designer / Wokwi / Tinkercad).
2. Соберите схему в соответствии с `circuit_image.png`.
3. Загрузите код в Arduino Uno и откройте монитор последовательного порта (Serial Monitor) на скорости **9600 бод**.
4. В первые 3 секунды система выполняет калибровку базового уровня освещенности.
